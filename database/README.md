# دليل قاعدة بيانات الأكاديمية (Database Structure & Migration Guide)

يحتوي هذا المجلد على جميع مخططات قاعدة البيانات والإصلاحات البرمجية الخاصة بنظام إدارة أكاديمية كرة القدم عبر Supabase (PostgreSQL).

## 📁 هيكلية المجلد:

### 1. `schemas/` (المخططات الأساسية):
- `supabase-schema.sql`: المخطط العام الأولي للجداول الأساسية (اللاعبين، الفرق، التدريبات، الاشتراكات، الحضور، الإحصائيات).
- `supabase-ultra-2026.sql`: المخطط المحدث المتكامل لعام 2026 مع كافة الدوال والإجراءات المخزنة (RPC) وسياسات الأمان (RLS).
- `ADMINS_SYSTEM.sql`: هيكل جدول مسؤولي الإدارة (الرئيس، نائب الرئيس، الكاتب العام، أمين المال) ونظام الصلاحيات.
- `NEW_FEATURES_SCHEMA.sql`: ميزات المقاييس البدنية، الملف الطبي، نظام التقييمات والشارات.
- `NOTIFICATIONS_TABLE.sql`: جدول الإشعارات المباشرة وتنبيهات الإدارة والمدربين والأولياء.
- `update_settings_schema.sql`: جدول إعدادات الأكاديمية، الهوية البصرية، والمواسم الرياضية.

### 2. `migrations/` (سجل التحديثات والإصلاحات):
- يحتوي على ملفات الترقية الدورية وإصلاحات التريغرز (Triggers) ومطابقة الحقول المالية التي تم إجراؤها على بيئة Supabase.

> 💡 **ملاحظة:** توجد أيضاً مخططات إضافية فرعية تحت المجلد `src/sql/` خاصة بالوحدات المتقدمة (مثل EMS للبطولات والمباريات وإدارة العتاد الرياضي).
