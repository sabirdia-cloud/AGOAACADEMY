# Roadmap for Pro Features

Phase 1: Admin & Tech Enhancements
1. Multi-language (i18n): i18next + react-i18next
2. Smart Export/Import: xlsx library integration
3. RBAC (Storekeeper, Doctor roles)

Phase 2: Medical & Physical
1. Medical File (Injuries + Doctor Appointments)
2. Physical Metrics (Height, Weight, BMI history)

Phase 3: Engagement & Gamification
1. Badges & Rewards system
2. Leaderboard per category
3. Internal Chat / Messaging

Phase 4: Finance & Invoicing
1. QR E-Invoices
2. Online Payment Gateway (Stripe/CIB mock or integration)

Phase 5: Offline & PWA
1. Service Worker for Offline Attendance
2. Push API notifications
