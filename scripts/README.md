# سكربتات وأدوات النظام (Scripts & Utilities)

## 📁 محتويات المجلد:

### 1. `build/` (سكربتات البناء والنشر):
- `build_pro_dist.sh`: سكربت بناء الحزم الثلاثية الشاملة (`ADMIN` و `COACH` و `PARENT`) وبوابة التوجيه الموحدة لـ Netlify.
- `build_for_netlify.sh` / `build_netlify_simple.sh`: سكربتات أتمتة الرفع والنشر السحابي.

### 2. `debug/` (أدوات الفحص والتصحيح):
- `debug_triggers.ts`: أداة فحص التريغرز في Supabase.
- `check_table.js`: التحقق من وجود الجداول وتناسق الأعمدة.
- `scratch.ts` / `scratch2.ts`: سكربتات تجريبية للاختبار السريع للـ API.
